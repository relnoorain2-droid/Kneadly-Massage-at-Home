                com.kneadlymassage.app.plus.monthly
                com.kneadlymassage.app.plus.annual
                com.kneadlymassage.app.plus.lifetime

**Product IDs must not contain hyphens.** Apple's documentation says hyphens are
allowed. The App Store Connect UI rejects them: "Only alphanumeric characters,
periods, and underscores are allowed." The UI wins. This is why product IDs do not
match the bundle ID — they don't need to, they only need to be globally unique.

## 4. CI rules learned the hard way

- **Never pin an Xcode version** (Xcode_16.2.app). Runner images change and the
  build dies. Use the newest installed Xcode instead.
- **Never name a specific simulator** (name=iPhone 16,OS=latest). Use
  -destination 'generic/platform=iOS Simulator'.
- build-check is a **compile-only** gate. Do not add test steps that need a booted
  simulator.

## 5. Verify before diagnosing

A replace script printing "nothing to commit, working tree clean" may mean it
**already succeeded on an earlier run**, not that it failed. Check the actual file
contents with Select-String before sending the user on a fix-it errand. This
mistake cost a full round trip.
